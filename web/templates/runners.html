Model sunucuda çalışmaz: kendi bilgisayarınızda (GPU'lu ya da değil) küçük bir program olan yerel çalıştırıcı sunucuya bağlanır, iş olup olmadığını sorar, görüntüleri indirir, modelinizle tahmin eder ve sonuçları geri gönderir. Bilgisayarınızda port açmanız gerekmez; model dosyanız bilgisayarınızdan çıkmaz.

{{ icon("terminal") }} Kurulum

  1. Çalıştırıcıyı indirin (uygulama kodu ve model kartları; model dosyası dahil değil) ve açın.
  2. Python 3.11 ortamı: 
    uv venv --python 3.11 .venv
uv pip install --python .venv -r requirements.txt
  3. Soldan anahtar oluşturun ve gösterilen komutu çalıştırın.
Model

--model birden çok kez verilebilir:

  • models/lite_v8.json=/yol/lite_net.pt: model kartı ve ağırlık dosyası (PC12 lite_v8 ağı)
  • /yol/model.onnx: yanında aynı adlı .json kartı olan ONNX modeli
  • python:/yol/model.py:Sinif: kendi Python sınıfınız
